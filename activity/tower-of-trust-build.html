Tower of Trust Build

Build a cup pyramid touching only strings — one rubber band, whole team.

Ages
8–12
Group
6–24 kids
Time
15–35 min
Where
Indoors
Prep
Some prep needed

Setup

Tie 4–6 strings to each rubber band so the whole team can pull it open together. Stack cups upside-down nearby.

Materials

  • plastic cups (30+ per team)
  • rubber bands with strings attached (one per team)
  • table space

Steps

  1. The challenge: build a cup pyramid using ONLY the rubber-band tool — no touching cups with hands.
  2. Each team member holds one string. Together they stretch the band open, lower it over a cup, and release to grip.
  3. Carry the cup to the build zone and stack it. One cup at a time.
  4. First team to build a 6-cup pyramid (3-2-1) wins.
  5. Debrief: what happened when one person pulled too hard? Teamwork is literally tension management.

Variations

Easier: Allow one designated 'placer' to use hands for the final set-down.

Harder: Build a 10-cup pyramid (4-3-2-1) or race two teams head to head.
