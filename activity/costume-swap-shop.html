Costume Swap Shop

Outgrown costumes find new kids: the community swap, run like a real shop.

Before you begin

Ages
4–14
Group
4–35 kids
Time
30–45 min
Where
Indoors
Prep
Some prep needed

Setup

A week ahead: invite families to donate clean, outgrown costumes. Sort donations by size on tables.

Materials

  • tables
  • hangers or bins
  • paper tags and markers
  • mirror (optional)

Steps

  1. Tag every costume with its size and a one-line description.
  2. Set up shop zones: trying-on corner, mirror station, checkout table.
  3. Shoppers 'buy' with kindness tokens - everyone gets the same number.
  4. Fitting-room helpers give honest, kind opinions.
  5. Leftovers get bagged for next year or donated onward - nothing wasted.

Variations

Easier: Classroom-only swap: bring one, take one, no tokens.

Harder: Add a repair station: simple fixes (seams, buttons) before costumes go out.

Safety

All costumes washed before the swap. Private trying-on space for kids who want it.

Source: Wikipedia: Clothing swap
