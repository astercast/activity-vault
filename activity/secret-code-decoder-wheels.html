Secret Code Decoder Wheels

Build a cipher wheel from cardstock, then trade coded messages to crack.

Ages
8–12
Group
2–30 kids
Time
30–50 min
Where
Indoors
Prep
Some prep needed

Setup

Cut two circles per kid: a big outer wheel and a smaller inner wheel (or use two paper plates, one trimmed smaller). Poke a center hole in each.

Materials

  • cardstock or paper plates (2 circles per kid)
  • brass paper fasteners
  • scissors
  • markers
  • rulers

Steps

  1. Write the alphabet evenly around the outer wheel's edge.
  2. Write the alphabet around the inner wheel's edge too, in a different color.
  3. Pin the small wheel on top of the big one with the fastener — it should spin freely.
  4. Learn the code: turn the inner wheel so A lines up under a different letter — that's your key. Write a message by finding each letter on the outer wheel and writing the inner-wheel letter beneath it.
  5. Trade coded messages with a partner. Share only the key (which letter A lines up under) and decode each other's notes.

Variations

Easier: Use pre-made wheels where kids just decorate and practice with a given key.

Harder: Invent a symbol code (pictures instead of letters) or crack a message with an unknown key by guessing common letters.

⚠️ Safety

Brass fasteners have a sharp point — the teacher pokes the center holes.
