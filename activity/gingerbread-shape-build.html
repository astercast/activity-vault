Gingerbread Shape Build

Engineer the tallest tower you can from graham crackers and icing 'mortar'.

Ages
6–12
Group
4–30 kids
Time
25–40 min
Where
Indoors
Prep
Some prep needed

Setup

Give each pair a plate, a stack of graham crackers, and a squeeze bottle of icing. Set a 20-minute build timer.

Materials

  • graham crackers
  • thick icing in squeeze bottles
  • paper plates
  • candy for decoration (optional)

Steps

  1. Plan first: sketch the tower on the plate's edge before touching food.
  2. Build with icing as mortar — let each layer set a minute before adding more.
  3. Measure the finished tower; the tallest standing tower wins.
  4. Decorate, photograph, and then — the best part — eat the engineering.

Variations

Easier: Build flat houses (walls only) instead of tall towers.

Harder: Test shapes: which holds more weight, a cube tower or a pyramid?

⚠️ Safety

Check for wheat, dairy, and egg allergies before anyone eats. Icing is sticky — wash hands and wipe tables after.
