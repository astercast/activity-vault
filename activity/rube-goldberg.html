Chain Reaction Machines

Teams build one link each of a giant chain-reaction machine — then debug the handoffs until the whole thing runs.

Ages
8–12
Group
6–25 kids
Time
60–60 min
Where
Indoors
Prep
Some prep needed

Setup

Gather junk-box materials; define the final task with the group.

Materials

  • dominoes
  • ramps or cardboard
  • marbles or balls
  • string
  • tape
  • pulleys (optional)
  • classroom junk

Steps

  1. Define the final task together: ring a bell, pop a balloon, drop a ball into a cup. Simple finish, complex journey.
  2. Split into teams; each team builds one 'step' of the machine using classroom junk — ramps, dominoes, pulleys, rolling balls.
  3. The rule: each step's output must trigger the next step's input. Teams negotiate the handoff points with their neighbors.
  4. Test each link separately, then run the full machine. It will fail. That's the activity — debug, adjust, rerun.
  5. Film the final successful run. Watch it in slow motion and narrate what each step does.

Variations

Easier: Build a 3-step machine instead of a full chain.

Harder: Require each step to use a different simple machine (ramp, lever, pulley).

⚠️ Safety

No heavy or sharp objects in the machines; test drops away from feet.
