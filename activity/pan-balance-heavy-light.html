Pan Balance Heavy Light

A two-pan balance and big things to test: one thing per side, watch which side goes down. That side is carrying the heavier one.

Ages 3–6 · 15–25 min · 2 materials

Ages
3–6
Group
2–12 kids
Time
15–25 min
Where
Indoors
Prep
Some prep needed

Setup

Set the balance on a table the group can see over and test it empty first: both pans level, beam swinging free, a balance that sticks or leans on its own gets fixed or swapped now, because a rigged result teaches the wrong lesson. Lay the object pairs out in a row where everyone can see them; every object must be big enough that no mouth is a plausible destination.

Materials

  • a simple two-pan balance scale (sturdy classroom kind)
  • pairs of big objects to compare (a big stone and a big sponge, a wooden block and a foam block, a full and an empty small bottle)

Steps

  1. Start with the empty balance and the one idea, in plain words: 'Two sides. Put one thing on each side. The side that goes DOWN is carrying the heavier thing.' Do the first test yourself with the most obvious pair you have, stone versus sponge, and let the beam say it.
  2. State the one rule for the testers: 'One thing per side, hands off while it settles.' A kid chooses the next pair, places one object in each pan, with help lifting where needed, and everyone waits with hands behind backs while the beam decides.
  3. Call the result together, every time, in the same sentence shape: 'The stone went down. The stone is heavier.' The sentence is the science report at three, and the repetition is what builds it.
  4. Prediction round: before each new pair is placed, hands go on heads for 'this one will go down', point at the object you back, then the balance settles it. Being wrong is data: 'We thought sponge. The beam says stone. The beam wins.'
  5. Finish with the equal test: the same object on both sides, two matching blocks, and the beam stays level. Say why, plainly: 'Same thing, same heaviness, nobody goes down.' Then objects go back in their row, in pairs, by the testers.

Variations

Easier: The adult places every object and the kids only call the result. Watching and naming is a full turn at this.

Harder: Three-object line-up: test pairs until the group can lay three tested objects in a row from heaviest to lightest, using only the beam's results.

⚠️ Safety

Objects are big, blunt and unbreakable, nothing glass, nothing with edges, nothing small enough to mouth. Hands stay off the balance while it settles: fingers under a dropping pan get pinched, so the hands-off rule is said before the first object and kept kindly. The scale stays on the table; nobody carries it loaded.

🤝 Inclusion notes

The chooser's job is a full turn done entirely by pointing: a kid who picks the pair, points their prediction, and calls, or signs, or shows, 'down!' when the beam moves has run the test; a partner's hands do the placing to their direction. Directing the test is doing the test, and the group hears it said.
