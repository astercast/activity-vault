Reindeer Grid Coding

Program a reindeer across a grid with arrow cards: no screens needed.

Before you begin

Ages
6–12
Group
1–24 kids
Time
25–40 min
Where
Indoors
Prep
Some prep needed

Setup

Print grids ahead; cut arrow-card sets into envelopes, one set per kid.

Materials

  • printed 5x5 grids (one per kid)
  • arrow cards (up, down, left, right)
  • reindeer tokens (paper clips or small toys)
  • star stickers (the barn)

Steps

  1. Place your reindeer on the start square and a star on the barn square.
  2. Lay out arrow cards to plan the whole route before moving anything.
  3. Run the program: move the reindeer one square per card.
  4. Bug! If you crash into a wall, go back and fix the cards.
  5. Trade grids with a partner and run their route.

Variations

Easier: Use a 3x3 grid with the barn two squares away.

Harder: Add blocked squares the route must go around.

Safety

None beyond the usual paper-and-scissors rules.
