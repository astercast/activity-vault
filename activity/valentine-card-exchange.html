Valentine Card Exchange

Every kid makes one, every kid gets one — nobody skipped.

Ages
5–12
Group
2–30 kids
Time
25–45 min
Where
Indoors
Prep
Some prep needed

Setup

Fold cardstock into cards ahead of time. Post the class list where everyone can see it so nobody is skipped.

Materials

  • folded cardstock cards (one per kid, plus extras)
  • markers, crayons, stickers
  • a class list so every kid gets one

Steps

  1. Hand out the class list and have each kid pick names — or assign everyone one secret recipient.
  2. Set out decorating supplies and give the group 20 minutes of quiet card-making time.
  3. Cards need a name, a kind sentence, and one decoration minimum.
  4. Collect the cards in a box and redistribute one per kid.
  5. Read-around: anyone who wants to can read their card aloud.

Variations

Easier: Pre-write sentence starters inside each card ('I like how you...').

Harder: Make pop-up cards with a folded tab inside.

⚠️ Safety

Keep scissors closed when not cutting; supervise any glitter so it stays on the paper.
