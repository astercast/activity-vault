Sock Puppet Studio

A sock, some buttons, and a brand-new personality.

Ages
5–10
Group
2–25 kids
Time
25–50 min
Where
Indoors
Prep
Some prep needed

Setup

Ask families for clean spare socks ahead of time. Set out decorating supplies and run one glue station.

Materials

  • clean socks (one per kid)
  • buttons, googly eyes, yarn
  • fabric glue or a low-temp glue gun
  • markers

Steps

  1. Pick a sock and decide your character: hero, monster, granny, alien.
  2. Glue or draw on eyes, add yarn hair, give it a mouth.
  3. While glue dries, write your puppet a name and one catchphrase.
  4. Puppet introductions: each character meets the group.
  5. Pair up and improvise a 2-minute puppet conversation.

Variations

Easier: Markers only — draw the whole face, no gluing.

Harder: Write and perform a 3-minute puppet play in pairs.

⚠️ Safety

Low-temp glue guns only, and one adult runs the glue station. Buttons are a choking hazard for the youngest kids — use drawn faces for under-5s.
